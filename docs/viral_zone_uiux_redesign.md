# Viral & Trend Zone UI/UX 재설계안

## 1. 한 줄 정의

`Viral & Trend Zone`을 음원 목록이 아니라 **완성된 9:16 숏폼을 탐색·재생·리믹스하고, 내 음원을 영상으로 완성하는 작업 공간**으로 재정의한다.

핵심 사용자 약속은 다음과 같다.

> 트렌드를 영상으로 발견하고, 마음에 드는 포맷을 내 음악으로 즉시 재제작한다.

## 2. 현재 구조 진단

### 현재 정보 구조

1. 페이지 소개 헤더
2. 상단 `Trending Viral Shorts Gallery` 20개 가로 슬라이드
3. 좌측 공개 음원 라이브러리
4. 우측 5단계 제작 조종석
   - 카테고리
   - 스타일
   - AI 기획
   - 음원 생성
   - 영상 생성
5. 하단 고정 오디오 플레이어

### 근본 문제

- 상단 카드는 9:16 `<video>`를 보여주지만 영상은 hover 시 무음으로만 움직인다.
- 카드의 재생 버튼은 `videoUrl`이 아닌 `audioUrl`을 전역 `<audio>`에 연결한다.
- 카드에 보이는 영상과 재생되는 음원이 서로 다른 미디어 객체라 동기화되지 않는다.
- 공개 라이브러리는 원형 앨범 커버 중심의 음원 UI이므로 “숏폼 영상 존”이라는 기대와 충돌한다.
- 20개 상단 샘플은 소수의 스톡 영상과 MP3를 반복 조합하므로 콘텐츠 고유성이 낮다.
- 감상과 제작이 한 화면에서 동시에 강하게 경쟁한다. 처음 방문한 사용자는 무엇을 먼저 해야 하는지 알기 어렵다.
- 데스크톱 hover에 의존해 모바일에서 영상 미리보기와 조작 의미가 약해진다.

## 3. 설계 원칙

1. **영상 우선**: 대표 자산과 기본 재생 단위는 MP4 또는 HLS 영상이다.
2. **한 개의 재생 주체**: 영상 재생 중 별도 오디오 플레이어를 동시에 구동하지 않는다.
3. **감상과 제작 분리**: `트렌드 탐색`과 `내 숏폼 만들기`를 상위 탭으로 분리한다.
4. **첫 프레임에서 이해**: 썸네일만 봐도 주제, 포맷, 길이, 사운드 사용 가능 여부가 보인다.
5. **발견에서 제작까지 한 번에**: 모든 영상에 `이 포맷으로 만들기` CTA를 제공한다.
6. **완성 영상만 공개**: `video_ready` 상태이며 실제 재생 가능한 영상 URL이 있는 콘텐츠만 피드와 라이브러리에 노출한다.

## 4. 제안 정보 구조

### 사이드 메뉴

- 메뉴명: `바이럴 & 트렌드`
- 보조 배지: `SHORTS`
- 진입 시 기본 탭: `트렌드 피드`

### 페이지 상위 탭

| 탭 | 역할 | 기본 행동 |
|---|---|---|
| 트렌드 피드 | 완성된 숏폼 탐색·재생 | 세로 영상 재생 |
| 포맷 라이브러리 | 카테고리·플랫폼별 레시피 탐색 | 미리보기 후 리믹스 |
| 내 숏폼 만들기 | 음원→영상 제작 워크플로 | 프로젝트 생성 |
| 내 프로젝트 | 생성 중·완료·실패 작업 관리 | 이어서 편집/다운로드 |

현재의 공개 음원 목록은 `/viral`에서 제거한다. 영상이 없는 음원은 다른 음원 전용 메뉴나 `내 프로젝트`에서만 관리하고, 바이럴 피드에는 노출하지 않는다.

## 5. 핵심 화면 설계

### A. 트렌드 피드 — 기본 화면

#### 상단 영역

- 제목: `지금 뜨는 숏폼`
- 설명: `영상으로 보고, 포맷을 가져와 내 음악으로 다시 만드세요.`
- 필터 칩: `전체 / TikTok / Shorts / Reels / 국내 / 글로벌`
- 정렬: `급상승 / 최신 / 재사용 많은 순`
- 주요 CTA: `+ 내 숏폼 만들기`

#### 데스크톱

- 중앙에 활성 9:16 영상 1개를 크게 표시한다.
- 우측에는 다음 영상 3~4개의 세로 썸네일 큐를 둔다.
- 좌측에는 제목, 크리에이터, 카테고리, 길이, 트렌드 지표를 둔다.
- 휠 또는 ↑↓ 키로 다음 영상으로 이동한다.

#### 모바일

- TikTok/Reels와 같은 한 화면 한 영상의 세로 스냅 피드로 제공한다.
- 우측 액션 레일: 좋아요, 저장, 공유, 음원/레시피 보기.
- 하단 CTA: `이 포맷으로 만들기`.

#### 영상 카드 필수 정보

- 첫 프레임/포스터
- 재생/일시정지
- 음소거 상태와 볼륨
- 진행률과 전체 길이
- 제목, 제작자, 카테고리
- 플랫폼 배지
- 플랫폼 및 완성 영상 배지
- `이 포맷으로 만들기`
- `레시피 보기`

### B. 상단 20개 슬라이드 개편

기존 20개 가로 슬라이드는 `오늘의 TOP 20` 랭킹 레일로 축소한다.

- 카드 비율: 9:16
- 기본 상태: 포스터 이미지 + 순위 + 제목 + 길이
- 포인터 hover: 3초 무음 프리뷰만 허용
- 클릭/탭: 중앙 상세 플레이어에서 **영상과 포함된 오디오를 함께 재생**
- 활성 카드에는 진행 링과 `재생 중` 상태를 표시
- 좌우 화살표 외에 드래그, 휠, 키보드 탐색 지원
- 모바일에서는 2.2장 정도가 보이는 스와이프 레일 사용

상단 카드의 재생 버튼은 MP3가 아니라 해당 영상의 `play()`를 실행해야 한다. MP3만 존재하거나 영상 URL이 유효하지 않은 항목은 TOP 20 데이터 후보에서 제외한다.

### C. 포맷 상세 패널

영상 또는 랭킹 카드를 선택하면 우측 시트/모달을 연다.

- 큰 9:16 영상 플레이어
- 포맷명과 한 줄 설명
- 0~3초 훅, 컷 템포, 카메라, 자막, 음원 스타일
- 플랫폼 적합도
- 사용된 음원 정보
- CTA 1: `이 포맷으로 만들기`
- CTA 2: `레시피 복사`
- CTA 3: `저장`

기존 `Copy Recipe`는 작은 영문 텍스트 링크가 아니라 의미가 분명한 보조 버튼으로 승격한다.

### D. 내 숏폼 만들기

기존 5단계 조종석을 별도 탭으로 이동하고 단계별 화면으로 단순화한다.

1. `콘셉트 선택` — 트렌드 포맷 또는 빈 프로젝트
2. `음원 선택` — 기존 곡 / 새 음원 생성 / 업로드
3. `영상 연출` — 장면, 자막, 캐릭터, 컷 템포
4. `미리보기` — 영상과 음원이 합쳐진 단일 타임라인
5. `내보내기` — TikTok, Shorts, Reels 프리셋

화면 우측에는 항상 9:16 미리보기를 고정하고, 좌측만 단계에 따라 바뀌게 한다. `음원 생성`과 `영상 생성`을 별개 결과 카드로 누적하기보다 하나의 프로젝트 상태로 묶는다.

## 6. 재생 UX 상태 규칙

### 영상 보유 콘텐츠

- 카드 클릭 → 활성 영상으로 전환 후 재생
- 영상의 내장 오디오 사용
- 다른 영상은 즉시 일시정지
- 화면 밖으로 60% 이상 벗어나면 자동 일시정지
- 자동재생은 muted로 시작하고 첫 사용자 조작 뒤 소리 상태를 기억
- 하단 글로벌 플레이어는 `동영상 모드`로 축소하거나 숨김

### 영상이 없는 콘텐츠

- 공개 트렌드 피드, TOP 20, 포맷 라이브러리에서 완전히 제외한다.
- 음원 생성 직후에는 공개하지 않고 `내 프로젝트`에 `영상 제작 필요` 상태로만 저장한다.
- 영상 생성과 최종 mux가 성공한 후에만 공개 가능 상태로 전환한다.
- 원본 음원은 제작 재개와 자산 관리를 위해 유지할 수 있지만 `/viral`에는 표시하지 않는다.

### 생성 완료 콘텐츠

- 최종 mux된 MP4를 단일 진실 공급원으로 사용
- 영상 플레이어와 별도 `<audio>`를 시간 보정으로 병렬 재생하지 않는다.
- 원본 음원은 편집/다운로드용 자산으로만 유지한다.

## 7. 콘텐츠·데이터 모델

각 공개 피드 항목은 최소한 다음 상태를 가져야 한다. 제작 중·실패·음원 전용 상태는 프로젝트 모델에서 별도로 관리하며 공개 피드 타입으로 변환하지 않는다.

```ts
type ViralShort = {
  id: string
  title: string
  creator: { id: string; name: string; avatarUrl?: string }
  status: 'video_ready'
  videoUrl: string
  posterUrl: string
  audioUrl?: string
  durationSeconds: number
  aspectRatio: '9:16'
  category: string
  platforms: Array<'tiktok' | 'shorts' | 'reels'>
  recipe: {
    hook: string
    cutCadence: number
    visualStyle: string
    captionStyle: string
    musicStyle: string
  }
  metrics?: {
    velocityScore: number
    saves: number
    remixes: number
  }
}
```

20개 샘플에 반복 스톡 영상을 임의 결합하는 방식은 제거한다. 각 영상은 실제 음원과 mux된 고유 MP4, 고유 poster, 정확한 duration을 가져야 한다.

## 8. 빈 상태·오류 상태

- 영상 로딩: 포스터를 유지하고 중앙에 작은 로딩 링 표시
- 영상 오류: `영상을 불러오지 못했습니다` + `다시 시도`
- 처리 중: 렌더 진행률과 예상 단계 표시
- 영상 URL 누락 또는 재생 검증 실패: 공개 목록에서 제외하고 운영 로그에 기록
- 피드 없음: 추천 포맷 3개와 제작 CTA 제공
- 네트워크 절약 모드: 자동재생 OFF, 탭 후 재생

## 9. 접근성과 반응형

- 모든 조작은 hover 없이도 보이게 한다.
- 카드 전체를 클릭 가능하게 하되 재생, 저장, 리믹스 버튼의 포커스를 분리한다.
- 재생/음소거/전체화면 버튼에 명확한 aria-label을 제공한다.
- 자막 ON/OFF와 대비 높은 캡션 배경을 제공한다.
- `prefers-reduced-motion`에서는 자동 미리보기와 확대 전환을 끈다.
- 키보드: Space 재생, M 음소거, ↑↓ 다음/이전, Esc 상세 닫기.

## 10. 성공 지표

- 영상 재생 시작률
- 3초 유지율 / 50% 시청률 / 완주율
- 영상당 `이 포맷으로 만들기` 클릭률
- 포맷 선택→제작 시작 전환율
- 제작 시작→MP4 생성 완료율
- 저장 및 재방문율
- 음원 생성→영상 완성 전환율

## 11. 구현 우선순위

### P0 — 정체성 회복

- 상단 카드 클릭 시 MP3 대신 영상+내장 음원 재생
- 공개 목록을 `video_ready + 유효한 videoUrl` 조건으로 필터링
- 재생 중인 미디어를 항상 하나로 제한
- 모바일에서 hover 의존 제거

### P1 — 탐색 경험

- `트렌드 피드 / 내 숏폼 만들기` 상위 탭 분리
- TOP 20 랭킹 레일 + 중앙 상세 플레이어
- 공개 라이브러리를 9:16 영상 카드로 변경
- 필터·정렬·포맷 상세 패널 추가

### P2 — 제작 전환

- `이 포맷으로 만들기`로 레시피와 음원 스타일 자동 주입
- 단일 프로젝트/단일 9:16 미리보기 구조
- 렌더 상태와 실패 복구 UX

### P3 — 고도화

- 개인화 추천
- 트렌드 속도 점수
- A/B 썸네일 및 훅 비교
- 플랫폼별 안전 영역·내보내기 프리셋

## 12. 핵심 수용 기준

- 사용자가 첫 화면에서 5초 안에 이곳이 “영상 숏폼 존”임을 이해한다.
- TOP 20 카드를 누르면 해당 영상과 소리가 동기화되어 재생된다.
- 영상이 없는 항목은 어느 공개 바이럴 화면에도 노출되지 않는다.
- 한 시점에 두 개 이상의 미디어 소리가 나지 않는다.
- 모바일에서 hover 없이 탐색·재생·리믹스가 가능하다.
- 트렌드 영상에서 제작 시작까지 최대 2번의 탭만 필요하다.
