# Healing Rain — 레시피 중심 제작 스튜디오

## 구현 범위 (2026-10-12)

메뉴: 일본 BGM 스튜디오 바로 아래, /healing-rain.
레시피 라이브러리 → 장면 설계 → 제작 계획. 10개 레시피(침대 열차, 숲속 텐트, 한옥, 오두막, 외딴 자연, 한적한 공원, 산사, 연못, 호수, 고산 마을).
서버 POST /api/healing-rain/plan은 허용된 설정을 검증하고 이미지·영상·음향 프롬프트를 컴파일한다. 외부 생성 호출, 과금, 업로드는 없다.
로그인 계정 저장과 브라우저 초안 저장을 구분한다. 계정 저장은 인증된 API에서 프롬프트를 다시 컴파일하고 소유자별 불변 스냅샷으로 보관한다. 같은 요청 ID 재시도는 중복 저장하지 않는다. 브라우저 초안은 명시적으로 계정에 가져올 수 있으며 원본을 지우지 않는다. JSON 내보내기도 지원한다.
카드에는 AI 생성 실사 대표 이미지를 사용한다. 설정 변경의 실시간 결과가 아님을 표시한다. 10개 WebP를 직접 제공해 이미지 최적화 경로의 일시적 누락을 피한다.

## 핵심 모델

- Recipe: 고정 컨셉, 소재/청취 위치, 음향 레이어, 움직임/루프 규칙, 버전.
- Project: 레시피 스냅샷, 사용자 연출, 강도/천둥, 팔레트/카메라/소품, 최종 길이.
- Generation: 프로젝트 전용 신규 원본, 모델/요청/비용/외부 job ID, 상태 및 출처.
- Edit: 영상·오디오 원본 참조, 구간/게인/크로스페이드, 천둥/번개 이벤트, 출력.
- Review: 연결 청감, 영상 이음새, 변형, 클리핑/무음, 실질적 작품 차이.

매 프로젝트 신규 자산 생성이 기본이다. 기존 음원은 레시피 미리듣기 참고 자료로 쓰고, 생성된 결과는 제작 이력에 보존한다. 기존 HealingRain의 SQLite와 WAV는 이동하거나 덮어쓰지 않는다.

## UX

레시피 카드에 장소와 핵심 재질 표시. 설계 화면에서 설정과 장면 설명을 동시에 보여준다.
강도 설정은 이미지·영상·음향에 함께 전달한다. 천둥은 기본 빗소리와 별도로 계획한다.
같은 컨셉 새 디테일은 구도/팔레트/소품 조합을 바꾸며 결과물 독창성을 보증하지 않는다.
30초 3/6/12개를 1/3/10시간으로 편집하는 구성을 명시한다. 3분 원본을 10시간짜리 신규 음원으로 오인시키지 않는다.
현재 완료된 기능과 생성/합성 미연결 상태를 명확하게 표시한다. 저장 오류, 빈 목록, 모바일/키보드 탐색 제공.

## 참고 이미지 기반 레시피 05 — 깊은 밤의 외딴 자연

2026-10-12 사용자 첨부 8장에 대한 시각 분석:
- 1~4: 어두운 수목, 작은 국소 광원, 젖은 계단/길의 반사, 비어 있는 정적인 화면. 밝은 광원이 화면 전체를 밝히지 않는 점을 채택.
- 5~6: 연못/호수 수면의 빗방울, 잎과 수면의 층위. 첨부는 야간으로 단정하지 않고 새 장면은 사용자 지시에 따라 깊은 밤으로 설계.
- 7: 이끼와 양치식물로 둘러싸인 좁은 협곡, 물길과 깊이감. 새 장면에서는 관광객·표지판을 배제하고 원본과 다른 지형/구도 구성.
- 8: 젖은 바위와 수직 낙수. 폭포 변형을 추가할 때 물소리를 별도 레이어로 설계하고 빗소리를 가리지 않도록 조절.

고정: 밤, 어두운 저채도 녹색/청흑색, 외딴 자연, 인물 없음, 고정 카메라. 불안감보다 안정감.
미세 움직임: 비, 잎에서 떨어지는 물, 잔물결, 느린 계곡 물. 밝기 변화/번개/카메라 이동은 기본 배제.
음향: 잎·바위·수면 위의 비와 낮은 계곡 물소리. 도심/차량/군중 소리 없음.
기본 변형: 이끼 협곡, 양치식물 바위와 작은 소, 숲 그늘의 젖은 돌, 외딴 골짜기 물길.

스크린샷은 컨셉 참고이며 공개 웹 자산으로 복사하지 않음. 실제 촬영지·촬영 사실을 주장하지 않음.
UI 5번째 카드와 장면 설정에 추가. 야외 전용 구도/색감 라벨 사용. 신규 이미지/음원 생성은 실행하지 않음.

## 침대 열차 연출 수정 — 소등 후 깊은 밤

사용자 참고 이미지 6장은 대부분 낮/일몰 좌석 객실로, 목표 분위기의 완성 레퍼런스가 아님. 큰 측면 창과 창문 빗물만 참고.
기본값: 폭우, 침대 곁 사선 고정 구도, 남색 저조도 객실. 천장등 소등, 희미한 취침등 하나. 잠든 성인은 이불에 덮인 작은 실루엣으로 배치.
창밖은 어두운 밤과 비, 먼 시골 불빛 몇 점. 가까운 숲/먼 불빛은 같은 방향으로 서로 다른 속도로 흐르며, 반복 경계에서 불빛의 갑작스러운 출현과 소멸을 검수.
창문을 화면 중심으로 삼고 실내 반사를 억제. 구도 참고 일러스트도 어둡게 수정. 실제 생성은 실행하지 않음.

## 레시피 10 — 사파 고산 마을의 폭우

사파에서 영감 받은 가상의 북부 베트남 고산 마을. 산비탈의 소박한 목조 가옥, 경사진 금속 지붕, 돌 기단과 젖은 길, 안개 속 계단식 경작지, 희미한 창빛. 깊은 밤 폭우가 기본.
지붕 타격음·처마 낙수·돌길 물튀김을 설계. 특정 실제 마을이나 민족의 건축을 정확히 재현했다는 주장은 하지 않음.
대표 이미지는 built-in image_gen 생성: photorealistic 16:9, low-key blue-black rainy night, secluded timber hillside houses, corrugated pitched roofs, faint warm windows, misty terraced mountains, dense natural rain, no people/vehicles/city/resort/festival/disaster/text/logo.
